# 体格差模拟器一览（中文汉化版）

这是 [qwertyaz111/my-site-hub](https://github.com/qwertyaz111/my-site-hub) 的**非官方中文汉化版**。

原作是日本创作者 qwertyaz111 制作的「体格差ツール・シミュレーター」系列（28 个 3D 体格差/互动姿势模拟器），本仓库将全部工具合并部署在**一个 GitHub Pages** 站点上，并把界面文案翻译为简体中文。

**在线使用：<https://louisyang841.github.io/my-site-hub/>**

## 与上游的区别

- 28 个子工具各自仓库的 `index.html` 被复制到本仓库对应子目录（如 `hug-simulator/`），代码逻辑未改动
- 界面文字、分享文案汉化为简体中文；`lang` 改为 `zh-CN`；字体换用 Noto Sans SC
- hub 主页的链接由绝对地址改为相对路径，单仓库即可部署整站
